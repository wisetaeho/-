함께모임 PWA 설치 패키지
=======================

구성
- index.html: 앱 본체
- manifest.webmanifest: 홈 화면 설치 정보
- sw.js: 오프라인 캐시
- icons/: 앱 아이콘

중요
PWA 설치는 HTTPS 주소에서 해야 합니다. 파일을 휴대폰에 다운로드해서 index.html을 직접 여는 방식으로는 '앱 설치'가 되지 않습니다.

가장 쉬운 무료 배포: GitHub Pages
1. PC에서 github.com에 로그인하고 새 Repository를 만듭니다.
2. Repository 이름을 hamkke-moim 으로 하고 Public으로 만듭니다.
3. 이 ZIP의 압축을 풀고 index.html, manifest.webmanifest, sw.js, icons 폴더를 저장소 최상위에 업로드합니다.
4. 저장소 Settings > Pages > Build and deployment에서 Deploy from a branch를 선택합니다.
5. Branch는 main, 폴더는 /(root)로 선택하고 Save를 누릅니다.
6. 잠시 기다리면 https://계정이름.github.io/hamkke-moim/ 주소가 만들어집니다.
7. 갤럭시 크롬에서 해당 주소를 열고 ⋮ 메뉴 > 앱 설치 또는 홈 화면에 추가를 선택합니다.

사용
- 참석자 탭에서 한 명씩 입력하거나 여러 명을 붙여넣습니다.
- 편성 탭에서 사람 이름을 터치해 선택한 뒤 원하는 그룹의 '선택한 사람을 여기로 이동'을 누릅니다.
- 그룹 안의 참석자는 이름 옆/아래의 '미배정' 버튼으로 다시 이동할 수 있습니다.
- CSV 저장으로 엑셀에서 열 수 있는 명단을 내보냅니다.
- 백업 파일 저장으로 JSON 백업을 보관할 수 있습니다.

개인정보 및 저장
- 참석자 데이터는 이 기기의 브라우저 localStorage에 저장됩니다. 서버로 전송하지 않습니다.
- 브라우저 데이터 삭제, 앱 제거, 기기 변경 시 데이터가 사라질 수 있으므로 정기적으로 백업 파일을 저장하세요.
- 개인용으로 설계되었습니다. 다른 휴대폰과 실시간 동기화되지 않습니다.
- 이름/나이/성별은 개인정보이므로 필요한 범위에서만 입력하고 백업 파일을 안전하게 보관하세요.
